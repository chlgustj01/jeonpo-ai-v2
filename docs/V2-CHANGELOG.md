## C. React V2

**Package 5** — 자세한 내용은 docs/devlog/PACKAGE-05.md.
- **실제 메뉴판 분석 502 해결:** 사고 토큰이 출력 한도를 소비해 JSON이 잘리던 문제. 분석·번역 토큰 예산을 재설정했다.

- **메뉴판 대응:** coverage 안내, "AI 추정 / 사진 글자에서 읽음" 출처 표시, 10개 상한.
- **보안:** Key를 헤더로 전달, dev-server 정적 허용 목록과 본문 크기 제한, 이미지 크기·MIME 검사.
- **성능:** 코드 분할로 초기 JS 563.34 KB → 351.80 KB (gzip 179.79 → 115.34 KB).
- **배포:** `vercel.json`, `vite preview` 프록시, 실제 API E2E(옵트인).
