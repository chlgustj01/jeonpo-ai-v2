## 3. UI/UX 변경 사항

**결과 화면 정보 순서**(요청 §3):
1. 분석 출처·범위: 식당, 분석 시각, 복원 여부, 범위(coverage), AI 추정 안내, 알레르기 미입력 안내
2. 전체 배너 + 주의 음식 요약
3. 음식 목록: 위험 배지, 첫 이유, DB 확인 칩. 위험도순 정렬, 탭하면 상세로 스크롤과 포커스 이동
4. 선택한 음식: 이름, 배지, 맵기, 이유 목록(⛔ 알레르기 / 🥗 식이 / ⚠️ 교차 접촉 추정 / 🌶️ 맵기 / ❔ 불확실). GREEN은 "일치 없음 — 안전 보장 아님"
5. 지식 DB 추가 확인(프로필 관련만, 기본 표시)
6. 직원에게 묻기(이 음식 / 주의 음식 전체, 4유형, TTS, 정지, 복사)
7. 식재료(AI 추정·사진 글자 칩)
8. ▶ 지식 DB 상세(근거, 출처, 문헌 문구 1회) — 접힘
9. ▶ 먹는 법·문화 — 접힘
10. ▶ 내 식사 기록(리뷰, 식당 연결) — 접힘
- 하단 고정: "이 음식에 대해 직원에게 묻기"

요청 순서(4 직원 질문 → 5 식재료)를 따르되, 프로필과 관련된 지식 DB 경고는 위험 이유 바로 아래에 둠("핵심 위험 경고와 필수 미확인 정보는 기본적으로 보이게 한다").

**그 외 변경:**
- **온보딩:** 목적 문구 → 언어 → 피해야 할 음식(표준 + 커스텀 + "알레르기 없음") → 맵기·식단·국가 → 시작. 시작하면 메뉴 탭으로 이동
- **지도 카드:** "📷 이 식당 메뉴판 찍기"(주 버튼)와 "🧪 데모 결과 보기"(보조 버튼)를 분리하고 내 프로필 일치 강조
- **리뷰:** 데모 리뷰에 "🧪 예시" 배지, 내 기록은 "📱" 배지와 📍 식당 표시. 국가명·맛 태그·맵기 라벨 번역
- **직원 질문 문구:** 지식 DB 관계(예: 참기름 → 참깨)는 "특히 참기름이 들어가는지 알려 주세요"라는 재료 확인으로 묻고, 교차 접촉 질문은 조리도구·기름·공간에 대한 일반 질문으로 분리(요청 §6). 한국어 문장에 영어 재료명이 섞이지 않도록 DB 한국어명만 사용
- **지식 DB 표시:** 조회는 영어 원문 재료(정확도 유지), 화면은 같은 위치의 번역 재료명. 재료 수가 다르면 잘못 짝짓지 않고 원문을 표시

디자인은 기존 vintage 토큰(`vintage-*`)과 컴포넌트(Card, Button)를 재사용했고, 새 UI 라이브러리나 디자인 시스템은 추가하지 않았다.

## 6. 검증 환경

- 감사 이후 `web/node_modules`가 WSL(Linux)에서 다시 설치되어, Windows에서는 TypeScript 7·Vite 8·Tailwind 네이티브 바이너리를 실행할 수 없다. 그래서 **타입 검사·빌드·서버는 모두 WSL**(Node v26.13.1)에서 실행하고, Playwright는 같은 `node_modules`의 JS CLI를 Windows Node로 실행했다(브라우저는 Windows 캐시).
- 테스트 대상:
  - React 개발 서버 `:5174`(사용자가 띄운 WSL Vite)
  - 프로덕션 미리보기 `:4175`(이번에 WSL에서 띄운 `vite preview`)
  - 둘 다 WSL 내부 `localhost:3000`의 `dev-server.js`(WSL)로 프록시한다.
- Windows 쪽 3000(PID 21536)과 이전 Windows 미리보기 4173은 종료하지 않았고 테스트에 사용하지 않았다.

## 7. 남은 한계

- **메뉴 가격 → 환율 연계 없음:** 가격 추출은 분석 API 변경이 필요해 범위 밖이다.
- **번역 재료명 짝짓기는 재료 수가 같을 때만 동작:** 다르면 지식 DB 상세(접힘)에 영어 원문이 표시된다.
- **대두 알레르기면 대부분 RED:** 실제 메뉴판에서 AI가 대두를 거의 모든 한식(고추장·된장)에 포함한다고 추정하기 때문이다. 판정 로직은 그대로이고, 직원 확인을 안내한다.
- **세션 복원 범위:** 같은 브라우저 탭에서만 동작한다(sessionStorage). 번역 캐시는 복원되지 않아 다른 언어로 복원되면 번역을 1회 다시 요청한다(서버 캐시가 응답).
- **토스트 언어:** 언어를 바꾸기 직전에 뜬 토스트는 최대 2.5초 동안 이전 언어로 남는다.
- **고유명사 번역 없음:** 식당명(영/한만), 데모 리뷰 본문(영어)은 번역하지 않았다.
- **첫 로드 JS 증가:** +19.7 KB(+5.6%).
- **데스크톱 레이아웃:** 448px 칼럼을 유지했다(U15).
- **실기기·음성 품질 미검증:** 실기기, 실제 음성 품질, 스크린 리더는 확인하지 않았다(§5 NOT RUN).
