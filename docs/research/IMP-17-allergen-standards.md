# IMP-17 — 국제 식품 알레르기 연구 및 규제 자료 조사

> 상태: **조사 완료, 코드 변경 없음.** 이 문서는 IMP-18(Master DB 설계)의 입력
> 자료다. 모든 항목에 조사 방법과 날짜를 기록했고, 1차 원문을 직접 확인하지
> 못한 항목은 "검증 필요"로 명시했다 — 임의로 근거를 만들어내지 않았다.

## 조사 방법

- 1차 자료(정부/국제기구 공식 문서)를 우선 확인했고, 가능한 경우 PDF/원문을
  직접 열람했다(예: 한국 MFDS 시행규칙은 PDF 원문을 직접 읽어 2차 출처의
  오류를 발견했다 — 아래 1-4 참고).
- 조사일: **2026-11-25** (이 문서의 모든 "검토일"은 이 날짜 기준).
- 웹 검색 도구(WebSearch)와 웹 페이지 직접 열람(web-fetch)을 사용했다.
  Claude의 사전 학습 지식만으로 기록한 내용은 없다 — 모든 수치는 이번
  조사에서 실제로 확인한 출처를 인용한다.

## 1. 국가별/기관별 규제 기준

### 1-1. 대한민국 식품의약품안전처 (MFDS)

| 항목 | 내용 |
|---|---|
| 법령명 | 식품 등의 표시·광고에 관한 법률 시행규칙 [별표 2] "소비자 안전을 위한 표시사항"(제5조제1항 관련), 1. 알레르기 유발물질 표시 |
| 개정일 | **2020. 9. 9.** (문서 자체에 명기됨) |
| 출처 | law.go.kr 원문 PDF(직접 열람, 2026-11-25) |
| **공식 목록(원문 그대로, 19종)** | 알류(가금류만 해당한다), 우유, 메밀, 땅콩, 대두, 밀, 고등어, 게, 새우, 돼지고기, 복숭아, 토마토, 아황산류(최종 제품에 이산화황 10mg/kg 이상 함유 시만 해당), 호두, 닭고기, 쇠고기, 오징어, 조개류(굴, 전복, 홍합 포함), 잣 |
| 표시 대상 범위 | 해당 원재료 직접 사용 / 그로부터 추출한 성분 사용 / 그걸 함유한 식품을 원재료로 사용 — 3단계 모두 포함 |

**⚠️ 발견한 사실 — 흔히 인용되는 "22종"은 1차 법령 원문과 불일치한다.**
여러 블로그·뉴스·2차 요약 페이지가 "식약처 알레르기 유발물질 22종"이라고
서술하지만, 이번 조사에서 law.go.kr의 PDF 원문을 직접 읽어 항목을 세어본
결과 **정확히 19개**였다(위 표). 2차 출처들은 항목을 하나씩 나열할 때도
19개만 나열하면서 총 개수만 "22종"이라고 적는 등 자기모순이 있었다 —
즉 "22종"이라는 숫자 자체가 어딘가에서 잘못 복제·확산된 것으로 보인다.
**이 문서는 1차 원문에서 직접 확인한 19종을 공식 수치로 채택**하고,
"22종" 주장은 근거를 찾지 못했으므로 폐기한다.

**중요한 설계적 함의**: 해커톤 원본의 `standardAllergens`(IMP-11 이전 19종)는
위 19종 법정 목록과 **정확히 1:1로 대응**한다(peanut=땅콩, pinenut=잣,
mackerel=고등어, shellfish=조개류 등). 즉 원본 팀이 이 시행규칙을 그대로
따라 설계했다는 것이 이번 조사로 사실 확인되었다. IMP-11에서 추가한
`fish`, `sesame`는 **이 한국 법정 목록에는 없는 항목**이다 — 즉 "한국
라벨링 의무"가 아니라 "국제 표준 + 실제 메뉴 데이터"에 근거해 추가한
것임을 명확히 해야 한다(아래 1-7 비교표 참고).

- 공공누리(KOGL) 라이선스 "유형 번호"(제1~4유형 등)는 두 데이터셋의

  뿐, 알레르기 성분 여부는 우리 쪽 `Ingredient_Allergens` 테이블에서
  별도로 매핑해야 한다(API가 대신 판단해주지 않는다).

## 4. 종합 — IMP-18에 제공하는 입력

1. **기존 19종(한국 MFDS 법정 목록)은 그대로 핵심 축으로 유지.**
2. **`fish`, `sesame`(IMP-11에서 이미 추가)는 "한국 법령"이 아니라
   "미국/EU/영국/Codex 국제 표준 + 실제 메뉴 교차오염 데이터"가 근거임을
   `Regulatory_Standards`/`Evidence_Sources`에 명시적으로 기록해야 한다**
   (지금 코드 주석에는 이 구분이 없다 — IMP-18 구현 시 보완 대상).
3. 추가로 검토할 만한 후보(지금 당장 추가하지 않음, IMP-18 설계 문서의
   "향후 후보" 섹션에서만 논의): 셀러리·겨자·루핀(EU/UK에만 있음),
   견과류 세분화(아몬드·캐슈·피칸 등 — 지금은 walnut/pinenut만 개별 id).
4. 공공 API(`COOKRCP01`, 원재료 정보)는 **"일반 레시피 근거"** 데이터로는
   쓸 수 있지만 **알레르기 자동 판정에는 쓸 수 없다** — 반드시 우리 쪽
   `Ingredient_Allergens` 매핑을 거쳐야 함.
